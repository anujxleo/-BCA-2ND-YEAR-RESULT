# **App Name**: BCA Result Portal

## Core Features:

- Student Search: Allow users to search for a student by name to view their results.
- Result Display: Display the student's result for each semester with a link to the official result page.
- Toppers List: Show a list of toppers based on a manually updated list of students.
- All Semesters View: A button to view the result of all semesters in one place.

## Style Guidelines:

- Primary color: Deep Blue (#1E3A8A) to convey professionalism and trust.
- Background color: Light Gray (#F5F5F5) for a clean and modern look.
- Accent color: Gold (#D4AF37) for highlighting important elements.
- Body and headline font: 'PT Sans' for a modern yet accessible feel.
- Use simple and professional icons for navigation and actions.
- Clean and structured layout to present information clearly.
- Subtle hover effects and transitions for a modern user experience.
